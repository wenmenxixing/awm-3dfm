01 / OVERVIEW

A world model that remembers.

Short-horizon geometry is only the beginning. A robot must preserve reliable observations, adapt as its view changes, and reconnect places it has seen before.

AWM-3DFM couples learned recurrent gates with test-time temporal–spatial regulation. Local memories grow into globally aligned submaps, while shared features support localization, dense reconstruction, and Gaussian rendering.

02 / METHOD

Local memory. Global consistency.

A shared visual encoder turns each incoming frame into geometry-aware tokens. Adaptive memory connects observations over time.

Encode & remember

Extract visual tokens and selectively propagate reliable historical geometry.

Track & map

Progressively refine camera poses and update the active local map.

Reconnect & align

Use loop-closure constraints and SL(4) submap optimization to correct global drift.

03 / ADAPTIVE MEMORY

Learn what to keep.
Regulate what to update.

Two complementary stages

Learned recurrent gating. Reset and update gates control how historical states interact with current image tokens, suppressing irrelevant information and integrating new evidence.

Test-time temporal–spatial regulation. Temporal state evolution and spatial observation–state consistency calibrate token-wise updates, preservation, and forgetting.

Submap-aware organization. Local memory limits the spread of errors; the global backend reconnects these local representations.

07 / OUR DATASET

Real robots. Diverse environments.

A self-collected multi-platform dataset captured with handheld devices, wheeled mobile robots, and quadruped robots across diverse indoor, outdoor, and indoor–outdoor environments.

Across platforms

Handheld devices, wheeled mobile robots, and quadruped robots bring different viewpoints, motion patterns, and platform-induced disturbances.

Across environments

Offices, long corridors, gardens, night roads, and mixed indoor–outdoor routes test reconstruction under varied scene layouts and illumination.

Across challenges

Moving pedestrians, repetitive structures, low light, and loop revisits challenge long-range memory and global consistency.

For quantitative trajectory evaluation, reference trajectories are generated with LiDAR-based FAST-LIO and transformed into the camera coordinate system using temporal synchronization and spatial calibration. The proposed model uses only RGB images; LiDAR supports the evaluation reference.
